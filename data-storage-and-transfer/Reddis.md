## Задание 1. Кеширование

Приведите примеры проблем, которые может решить кеширование.

Приведите ответ в свободной форме.

Кеширование помогает решить такие проблемы:

1. Медленная загрузка данных

Например, приложение каждый раз запрашивает одни и те же данные из базы. Если эти данные положить в кеш, ответ будет приходить быстрее.

Пример: список популярных товаров, профиль пользователя, настройки сайта.

2. Высокая нагрузка на базу данных

Если тысячи пользователей постоянно запрашивают одну и ту же информацию, база данных перегружается. Кеш забирает часть запросов на себя.

Пример: главная страница интернет-магазина с одними и теми же категориями.

3. Большое время ответа API

Если внешний сервис отвечает медленно, результат можно временно сохранить в кеше и не обращаться к этому сервису каждый раз.

Пример: курсы валют, погода, данные доставки.

4. Высокая нагрузка на сервер

Когда сервер постоянно заново считает одни и те же данные, кеш позволяет сохранить уже готовый результат.

Пример: отчёт, статистика, количество просмотров, агрегированные данные.

5. Проблемы при временной недоступности внешнего сервиса

Если внешний API временно не отвечает, приложение может показать старые данные из кеша.

Пример: сайт показывает последнюю сохранённую погоду или старый список новостей.

6. Медленная загрузка статических файлов

Картинки, CSS, JavaScript можно кешировать в браузере или CDN, чтобы не скачивать их заново.

Пример: логотип сайта, стили, шрифты, иконки.

Коротко: кеширование решает проблемы скорости, нагрузки, повторных вычислений и частичной отказоустойчивости.
