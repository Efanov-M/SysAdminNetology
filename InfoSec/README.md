
### Задание 1

При сканировании Metasploitable с помощью Nmap были обнаружены открытые сетевые службы, среди которых FTP, SSH, Telnet, HTTP, Samba/SMB, MySQL, PostgreSQL, VNC, IRC и другие.

Для определения служб и их версий использовалось сканирование:

```bash
nmap -sV
```

После определения версий служб был выполнен поиск известных уязвимостей.

В качестве примеров уязвимых служб Metasploitable можно привести:

1. **vsftpd 2.3.4** — уязвимая версия FTP-сервера, содержащая backdoor и позволяющая получить удалённый доступ к системе.
   Exploit-DB: EDB-ID 17491.

2. **Samba 3.0.20** — уязвимость `Username Map Script`, позволяющая выполнить произвольные команды.
   CVE-2007-2447, Exploit-DB: EDB-ID 16320.

3. **UnrealIRCd 3.2.8.1** — версия IRC-сервера с backdoor, позволяющим удалённо выполнять команды.
   Exploit-DB: EDB-ID 16922.

Таким образом, Metasploitable содержит большое количество намеренно уязвимых и устаревших сетевых служб, которые могут быть обнаружены при сканировании и дальнейшем анализе их версий.

### Задание 2

Были проведены четыре вида сканирования:

```bash
sudo nmap -sS    # SYN
sudo nmap -sF    # FIN
sudo nmap -sX    # Xmas
sudo nmap -sU    # UDP
```

**SYN Scan (`-sS`).** Nmap отправляет TCP-пакет с флагом SYN. Открытый порт отвечает `SYN/ACK`, закрытый — `RST`. Полное TCP-соединение при этом не устанавливается.

**FIN Scan (`-sF`).** Отправляется TCP-пакет только с флагом FIN. Закрытый порт отвечает `RST`. Если ответа нет, Nmap определяет состояние как `open|filtered`.

**Xmas Scan (`-sX`).** Отправляется TCP-пакет с одновременно установленными флагами `FIN`, `PSH` и `URG`. Закрытый порт отвечает `RST`, отсутствие ответа интерпретируется как `open|filtered`.

**UDP Scan (`-sU`).** Вместо TCP-пакетов отправляются UDP-пакеты. Если приходит ICMP `Port Unreachable`, порт считается закрытым. Если UDP-служба отвечает, порт считается открытым. При отсутствии ответа Nmap часто не может отличить открытый порт от фильтруемого и показывает `open|filtered`.

В Wireshark основное отличие хорошо видно по структуре пакетов и TCP-флагам: SYN использует `SYN`, FIN — `FIN`, Xmas — `FIN+PSH+URG`, а UDP Scan вообще не использует TCP-флаги.
